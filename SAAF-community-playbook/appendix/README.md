# Appendix

Templates, checklists, and a glossary. The fast-reference half of
the playbook.

The main playbook sections explain *why*. The appendix provides
*what* — fillable forms and tickable lists you can use directly.

## How to use

The checklists are designed to be copied per session and ticked off.
Don't memorise them; tick them.

The templates are designed to be copied, filled, and used. Don't
treat them as inviolable; adapt them to the chapter's context, but
keep the structure.

The glossary is for the moment when a new captain reads the playbook
and trips over a term.
