# Measuring Value

How to measure the chapter's contribution in a way that informs
decisions — for executives, for sponsors, for the chapter itself.

The core insight: measure a small number of value pillars
*consistently*, in the language executives already use, and connect
metrics to decisions, not to dashboards.

## The core principle

> **Community metrics only matter if they inform decisions.**

If a metric does not change what someone does, it does not need to
exist. Most chapters track too much. Few chapters track the right
things.

Read [value-pillars-and-metrics.md](value-pillars-and-metrics.md)
first. Don't read the others until you have settled on the pillars.
