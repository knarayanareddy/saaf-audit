You need a GitHub Personal Access Token (PAT) to load the leaderboard. Everyone can open this page — it's read-only.

How to create a PAT:
  1. Go to github.com/settings/personal-access-tokens/new
  2. Name: SAAF Leaderboard
  3. Expiration: 30 days
  4. Repository access: select SAAF-Project/SAAF-Project
  5. Permissions → Repository permissions:
    • Pull requests → Read
    • Contents → Read
  6. Click Generate token → copy → paste above → Connect

Need help? See the GitHub docs on fine-grained PATs
