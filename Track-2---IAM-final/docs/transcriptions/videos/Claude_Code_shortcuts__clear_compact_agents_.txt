This is very similar to slash clear, but instead of clearing the whole conversation, it will summarize what you guys have been talking about and it'll use that as context. This command is perfect if you ever have a repeated task that you're always having to run. Instead of having to write the prompt out every single time, you can do slash agents, create a new agent, put in your specific instructions of what you want it to do.
