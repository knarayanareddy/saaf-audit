If you're still building NADN workflows manually or using the NADN AI workflow builder, you are wasting a ton of time and need to be using the Cloud Code NADN Toolkit instead. Say for later and follow for more AI tips. The Cloud Code NADN Toolkit is made up of two distinct parts. The first is the NADN MCP server, which essentially gives Cloud Code access to your NADN instance. It allows it to deploy workflows, pull workflows, edit workflows, edit partial workflows, and it gives it a repository of NADN workflow knowledge of over 2,800 example workflows to pull from when it's building your workflows for you. It can also validate workflows and much more. By connecting this MCP server to Cloud Code, which is an AI agent that lives in the terminal of your computer, it can now do everything that you could do in NADN in your web browser. The second part of this Toolkit is the NADN skills repository, which you can find on GitHub by searching NADN-skills. This is a repository of seven NADN skills that essentially teach Cloud Code how to use the NADN MCP server correctly. How to navigate between tools, when to use which tool over another tool, and how to build workflows that will actually work on a one-shot prompt.
