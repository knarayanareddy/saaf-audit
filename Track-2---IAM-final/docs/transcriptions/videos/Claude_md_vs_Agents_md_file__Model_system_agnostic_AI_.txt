Stop using Claude MD files, do this instead. Ask Claude to create an agents.md file and copy the contents of your Claude MD file into that file. Then create a simlink from Claude MD to agents.md. The reason for this is that most agents respect the agents.md format and Claude respects simulings. So whilst it looks for rules in the Claude MD files actually points into the agents.md file, this means your team is going to be able to use whatever agent they want, be it GPT codex, open code, pretty much any other agent will support agents.md. And you'll all be contributing rules to a single source of truth and go step further by adding this to your root Claude MD files that at any time you run init or create a project, it prioritizes updating the agents.md file instead of the Claude MD file.
