## How to submit

1. Copy the template: `cp docs/plans/plan-template.md plans/hackathon-4/firstname-lastname-slug.md`
2. Fill in the template — mark unfinished sections as TBD
3. Add your name to the `Claimed By` field if you're actively building
4. Open a pull request to `main`

Full guide: [`docs/getting-started.md`](../../docs/getting-started.md)
