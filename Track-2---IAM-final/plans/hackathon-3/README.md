# Hackathon #3 — Submitted Plans

**Session:** Hackathon 3 (Session 4)  
**Date:** April 21, 2026  
**Venue:** Wolters Kluwer, Alphen aan den Rijn  

This folder contains plans submitted ahead of (and during) Hackathon #3. The session focus is **building more, sending less** — all plans target concrete prototypes that can be demonstrated on the day.

Key infrastructure for Hackathon #3:
- **Strapi sandbox** with synthetic datasets (Jira incidents, access reviews) for agent testing
- **RAG knowledge base** shared across all participant agents
- **Skills matching** so every participant works on something that fits their background
