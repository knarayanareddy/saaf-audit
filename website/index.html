About SAAF

Stop reinventing the wheel.
Start building together.

Auditors are overwhelmed with AI tools but often lack the in-depth understanding of how these systems can be deployed safely, reliably, and in line with legislation such as the EU AI Act. It leads to the frustration of "not seeing the forest for the trees", which means we still end up doing the same manual work as before.

SAAF opts for a hands-on approach: "Learning by building." Participants collaboratively design and build AI audit automation skills at a series of hackathons, gaining deep understanding and direct applicability within their own organizations.

AI-Agnostic
Works with Copilot, Gemini, Claude, or any local LLM. No vendor lock-in, integrates into your existing IT stack.
Co-Creation
Shared GIT repository of scripts, prompts, policies, and lessons learned. Access to a validated, open-source knowledge base.
Shared Standards
Uniform output formats ensure interoperability and traceability, crucial for compliance and cross-organization comparability.
🚀

The Vision

The SAAF project is a joint framework that enables organizations to make AI-powered audit processes manageable, explainable and reproducible, without depending on one specific supplier technology.

The mission is co-creation, not competition. Everything is stored in a shared GIT repository: scripts, prompts, policies, lessons learned. Collaboration is the engine.

Our Story

How SAAF came to be

From a single roundtable to a Foundation in the making, built by auditors, for auditors.

Eduward van de Kamp and Mathijs Schouten both work at Mollie. From there, together with Frank van Dissel, they organized a roundtable with audit leaders from banks, insurers, and tech companies like Booking.com. The conclusion: a tech revolution is underway, but practical AI knowledge is missing. SAAF was born to fix that, and is being set up as a non-profit Foundation (Stichting).

Build, not just use

We teach auditors to build their own AI agents, hands-on and open source. Two directions: agents that execute audit processes, and agents that help developers achieve audit, security, and governance by design.

Mollie is where it all started: hosting the founding roundtable and the first two SAAF sessions. SAAF has since grown into an independent initiative, supported by IIA, NOREA, ISACA, NBA, and ForHumanity.

The Framework

Four Building Blocks

SAAF agents are assembled from four standardized components, ensuring interoperability and traceability across all participating organizations.

Prompts

Domain-specific audit prompts and system instruction files, crafted for internal audit use cases to ensure consistent and reliable AI behavior, regardless of which AI system you use.

Prompt Library

Tools

Scripts, API connections, version control integrations, and file automation utilities that power agent capabilities across audit workflows, built to work with any tech stack.

Scripts · APIs · Integrations

Regulatory

Control mappings for the regulatory frameworks applicable to your organization, ensuring audit agents operate within the right compliance and security boundaries.

Standards & Controls

Outputs

Standardized report formats enabling cross-organization comparability, auditability, and traceability. Output format depends on the use case: structured data, documents, or dashboards.

Structured · Readable · Traceable
