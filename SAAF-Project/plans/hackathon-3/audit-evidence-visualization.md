## 2. Problem Statement

Audit reports are text-heavy. Control maps, risk heat maps, and policy-control matrices that would make findings immediately clear to management are instead described in dense prose or basic Excel tables. Auditors lack design skills; BI teams are too slow.

Claude can generate styled HTML visualizations from structured audit data in seconds — visual outputs that can be embedded directly in audit reports or presented to audit committees without requiring Tableau, Power BI, or a designer.

---

## 3. Use-Case Type and Scope

**Audit domain:** Internal Audit — Reporting / Audit Committee Communication

**Applicable standards:**

- IIA IPPF — Standard 2420 (Quality of Communications)
- EU AI Act — Art. 13 (Transparency) — AI-generated visuals must be labeled as such

**In scope:**

- Claude generates styled HTML from structured audit data (JSON findings, RCM tables, control matrices)
- Visual types: risk heat map (likelihood × impact), control status traffic light, policy-control coverage matrix, finding timeline
- Output: standalone `.html` file, embeddable in reports, renderable in browser
- No external charting libraries — pure HTML + inline CSS + SVG (no CDN dependencies)

**Out of scope:**

- Interactive dashboards (see `power-bi-audit-dashboard-mcp.md` for that)
- Automated report generation (those are Markdown-based in existing plans)
- Real-time data binding (static snapshot per audit run)

## 5. Prompts

### System prompt (draft)

```
You are an audit visualization specialist.
Given structured audit data (JSON), generate a standalone HTML page that visualizes the data clearly for an audit committee audience.

Rules:
- Use only inline HTML, CSS, and SVG — no external libraries or CDN links
- Use professional color palette: Red=#C0392B, Orange=#E67E22, Green=#27AE60, Gray=#7F8C8D
- Label all AI-generated content with a small footer: "Generated by SAAF Audit Agent — review before use"
- Every data point must have a tooltip showing the source value
- The page must render correctly when opened in a browser without internet access

Output only the complete HTML — no explanation, no markdown fences.
```

### Example user prompts

**Prompt 1 — Risk heat map:**
```
Generate a risk heat map from this RCM data (JSON attached).
X-axis: likelihood (1-5), Y-axis: impact (1-5).
Each risk plotted as a circle with tooltip showing risk name and control status.
Color: red (high), orange (medium), green (low).

Generate a policy-control coverage matrix from this data.

Cell: green checkmark (covered), orange dash (partial), red X (not covered).
Add a summary row: coverage percentage per policy.
```

## 6. Tools and Techniques

### Approach

A Python script reads structured audit data (JSON), builds a prompt with the data embedded, and calls Claude to generate the HTML. The HTML is written to `outputs/visuals/`. For batch runs (multiple visuals for one audit), each visual type is generated sequentially and linked from a master index page.

### Example script or pseudocode

```python
import anthropic
import json
from pathlib import Path
from datetime import date

client = anthropic.Anthropic()
OUTPUT_DIR = Path("outputs/visuals")
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)

VISUALIZATION_SYSTEM_PROMPT = """..."""  # (see above)

def generate_visual(
    data: dict,
    visual_type: str,
    instructions: str,
    output_name: str
) -> Path:
    prompt = (
        f"Visual type: {visual_type}\n"
        f"Data: {json.dumps(data, indent=2)}\n"
        f"Instructions: {instructions}\n"
        "Generate the complete standalone HTML."
    )

    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=4096,
        system=VISUALIZATION_SYSTEM_PROMPT,
        messages=[{"role": "user", "content": prompt}]
    )

    html = response.content[0].text
    out_path = OUTPUT_DIR / f"{output_name}-{date.today()}.html"
    out_path.write_text(html)
    print(f"  Visual written to: {out_path}")
    return out_path

# Example: generate risk heat map from RCM JSON
rcm_data = json.loads(Path("data/rcm-access-management.json").read_text())
generate_visual(
    data=rcm_data,
    visual_type="risk_heat_map",
    instructions="Plot each risk as a circle. Tooltip shows risk name, rating, and owner.",
    output_name="risk-heat-map-access-mgmt"
)
```

**Tech stack used:** Python 3.9+, Claude API (claude-sonnet-4-6), HTML/CSS/SVG (no external dependencies)

**Intended file location:** `tools/scripts/generate-audit-visual.py`

### Applicable standards

| Standard | Relevant controls |
|---|---|
| IIA IPPF 2420 | Quality of communications — visuals must be accurate, timely, and clear |
| EU AI Act Art. 13 | Transparency — all AI-generated visuals labeled with generation method |

### Claude / AI tool usage notes

The visualization agent receives structured JSON data (finding counts, risk ratings, control statuses) — no free-text audit evidence is sent to the API. Synthetic data for testing; real data only after auditor review and approval of the underlying findings.
