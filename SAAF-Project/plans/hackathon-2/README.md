## How to submit your plan

1. Copy [`docs/plans/plan-template.md`](../../docs/plans/plan-template.md) to this folder: `firstname-lastname-your-slug.md`
2. Fill in all sections; mark unfinished sections as "TBD"
3. Open a pull request — the organizers will add a row to the index above

See [`docs/getting-started.md`](../../docs/getting-started.md#hackathon-2--submitting-a-plan) for the full step-by-step guide including how to use Claude Code and `gh` CLI to submit.
