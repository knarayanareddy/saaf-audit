# SAAF Hackathon #5 — How Today Works

**Today's theme: harden what we already have. NO NEW AGENTS.**

We have built a lot over five sessions. Now we make it *trustworthy*: stress-tested, documented, observable, and ready for real use. You are the auditors — so today you audit the agents.

## The flow (read this once)

1. **Form a team of 3–4.** Mix roles if you can (auditor + vaktechniek + analyst + developer).
2. **Pick ONE assignment PDF** from the handout folder (A1–A7). Choose one that fits an agent you **built** or would **adopt in your own business** — that is where the value is. If no agent fits, take **A5 — Portal Experience**.
3. **Do the assignment. You have 3 hours.** Each PDF is self-contained — everything you need is inside it. You do **not** need to read the portal or use git.
4. **Hand in one Word or PDF document** to the **Hand-in folder** before **16:30**.

- **Handout folder:** `https://drive.google.com/drive/folders/1H6Q6Ws7R5TZBo2CPNeDmOzwhUEB-E03O`
- **Hand-in folder:** `https://drive.google.com/drive/folders/1NuRZS1jQ5o5sAfnGTf7ULO2K3Z6dGJxG`

## Rules of the day

- **Synthetic / dummy data only.** Never real audit evidence, personal data, or credentials.
- **Full = full.** If a team or assignment is full, pick another open one.
- **Quality over quantity.** One genuinely useful, honest result beats five rushed ones.
- **Finding problems is the goal.** A clear, well-evidenced failure is a *win* today.
- **English only**, so everyone can reuse your work.
