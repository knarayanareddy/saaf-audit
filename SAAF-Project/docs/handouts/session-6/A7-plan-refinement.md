# A7 — Plan Refinement & Acceptance Criteria

**For:** Vaktechniek / Auditors · **Team size:** 3–4 · **Time:** 3 hours

## Goal
Take **one existing plan** and make it genuinely buildable: tighten the scope, and add **testable acceptance criteria** so anyone picking it up knows exactly what "done" means. Hand in the improved plan text.

## Why it matters
Many plans are vague, which is why agents drift or stall. A sharp plan with clear acceptance criteria is the difference between a weekend prototype and something a team can finish and trust.

## Pick your plan
Choose an existing plan — ideally one for an agent you'd use, or one that looks promising but underspecified. Note the plan title and where it lives.

## What to do
1. **Read & diagnose (40 min).** Read the plan. Where is it vague? What is missing — clear scope, success measure, output format, risks, human-review step? Use the 1–5 rubric below to score it as-is.
2. **Tighten the scope (40 min).** Rewrite the problem statement and the in-scope / out-of-scope lines so they are specific and achievable. Cut anything that isn't core.
3. **Write acceptance criteria (50 min).** Add **≥5 testable acceptance criteria** — concrete pass/fail statements that prove the agent works (see examples).
4. **Add what's missing (20 min).** Make sure the plan names: the output format, the top risks + their controls, and the human-review gate.
5. **Re-score (10 min).** Score the improved plan on the 1–5 rubric and state what moved it up.

## Inline reference
**Quality rubric (1–5):** 1 = bare outline · 2 = thin · 3 = draft, gaps in tools/regulatory · 4 = strong, most parts complete · 5 = production-ready (clear scope, prompts, tools, regulatory mapping, output format, honest status).

**Acceptance criteria are testable.** Examples:
- *"Given a policy PDF, the agent returns ≥1 control per page or explains why none."*
- *"Every finding includes a risk rating and a recommendation."*
- *"The agent refuses to run when the input file is empty."*
- *"Output validates against the finding fields (id, title, risk_rating, observation, recommendation)."*

## Definition of Done
- [ ] Plan named + as-is rubric score
- [ ] Rewritten, tightened scope (in/out)
- [ ] **≥5 testable acceptance criteria**
- [ ] Output format, top risks + controls, and human-review gate present
- [ ] New rubric score + what improved

## SMART
**S** one plan · **M** ≥5 acceptance criteria + a rubric delta · **A** no coding · **R** sharper plans get built · **T** 3 hours.

## Suggested time-box
40 diagnose · 40 scope · 50 acceptance criteria · 20 fill gaps · 10 re-score · 20 write-up & hand in.
