> **[Image on this slide]** ## Prompt Injection vs. Jailbreak — Whiteboard Explainer

This whiteboard diagram distinguishes **prompt injection** (a "control hijack") from jailbreaking, explaining that prompt injection occurs when malicious instructions are hidden inside content an AI agent processes — such as emails, documents, or web pages — causing the agent to take unintended actions using its legitimate access and tools.

The key insight for auditors is captured in the **Mental Model**: an AI agent behaves like an *intern with admin rights* — fast, helpful, literal, and **very easy to manipulate** — meaning the attack surface is pure language, requiring no malware or broken authentication.

For internal audit specifically, the framework highlights three critical risks: **data exfiltration, unauthorized actions, and privilege escalation**, and recommends treating this as a **trust-boundary problem** rather than a prompt problem — with mitigations including separating "read" from "act" permissions, human-in-the-loop for high-risk actions, and treating all external content as hostile.

The closing principle is directly relevant to AI audit governance: **"If text can trigger actions, then text must be treated like code."**
