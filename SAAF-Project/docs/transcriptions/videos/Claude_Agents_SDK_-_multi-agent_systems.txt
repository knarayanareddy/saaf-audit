If you use Cloud Code and you want to build the most powerful multi-agent systems that you can with the tool, you need to check out the Cloud Agents SDK. In simple terms, the Cloud Agents SDK allows you to launch an instance of Cloud Code in its own container and sandbox without interacting with it in the terminal. This is done with a TypeScript or Python script and essentially allows you to launch an instance of Cloud Code with all of the same capabilities and tools that Cloud Code has, but it has its own access to its own desktop computer and all the tools that Cloud Code normally has. Because you can launch agents with a script instead of starting it in your own terminal, you can launch as many instances of Cloud Code in parallel as you want. You can then use Cloud Code hooks to monitor the tool usage and the actions that all of your agents are taking to have a multi-agent observability framework. You can instruct all the instances of Cloud Code that you have running to use the same external document system as a context system so that they can coordinate what they're doing. Each agent can also run a script to launch another agent, which itself can launch another agent, so you can have an infinite branching tree of Cloud Agents.
