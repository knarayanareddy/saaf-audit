You need to stop using MCPs inside of Cloud Code, especially if you can use a CLI instead. The best tool to help you do that is CLI anything. This is an open-source tool that allows you to point Cloud Code at any open-source project and create a CLI tool for that software. Now, this is from the same team that created LightRag, Rags, anything, NanoClaw, so they've done a ton of open-source AI projects. And the setup and execution with this tool is so easy. So, definitely try it out if you're looking to upgrade your Cloud Code game.
