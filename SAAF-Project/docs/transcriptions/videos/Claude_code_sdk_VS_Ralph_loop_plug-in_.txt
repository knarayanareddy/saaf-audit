If you're like most people trying to use Ralph loops, you probably installed the Ralph Wigham plugin from Cloud Codes Plugin Marketplace. This plugin misses one of the most important things you need to have to have a good Ralph loop because the Ralph loop happens within the same session and doesn't account for information loss during auto-compact cycles. The original Ralph loop is a loop that happens outside of any individual agent's context window so that you can actually control what information makes it in and out of each agent's context window. The Cloud Code Ralph loop plugin happens within the context window of one agent and doesn't account for auto-compact cycles that might happen if the context window gets filled and you can't control the context that makes it from one compact cycle over to the next clean context window. To use a Ralph loop correctly, you're going to want to create a loop that triggers an instance of Cloud Code SDK rather than using the loop in the actual Cloud Code command line interface so that you can have external progress tracking documents where individual instances of Cloud Code SDK can keep track of the progress that they've made on an individual task so that when a new instance gets booted up, it can check the progress document and retain as much context as you want to be passed between context windows.
