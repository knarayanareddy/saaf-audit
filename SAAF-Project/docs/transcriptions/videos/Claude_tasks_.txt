So Cloud Code just dropped a new feature called Tasks, and it's very heavily inspired by the viral GetShitDone framework and Ralph Loops. You can think of this new Tasks feature like the Tadulist tool on steroids. Now instead of having your Tadulist only able to be seen by one agent, they're turned into task files that live in a folder in your project and can be worked on by many agents at the same time, or by a sequential loop of subagents. This is where I see this feature working really well with GetShitDone or Ralph Loops or even taking over some of the functionality of those systems because now Cloud Code will be inclined to create a list of externalized task files that can be worked on by multiple agents at the same time, and then use subagents or background subagents either in parallel or in sequence to accomplish those tasks. Subagents themselves can also interact with the Tasks folder and add new tasks if they encounter while they're working. To point multiple agents to the same task directory, you just have to configure a Tasks environment variable in these settings.json file.
