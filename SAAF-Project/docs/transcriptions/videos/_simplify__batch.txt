andthropic just improved the process for two of the most annoying parts of coding with AI. Cloud Code now ships with slash simplify and slash batch. These are bundled skills, not custom hacks. Slash simplify reviews, your recent changes and launches three agents in parallel. Reuse, quality and efficiency. So after a feature or bug fix, run it before the PR. It cleans the stuff reviewers usually flag. Slash batch is for bigger jobs. It studies the repo, breaks the migration into 5 to 13 independent units, then shows you the plan. Approved and isolated agents fan out in git work trees, run tests and open the pull requests. This is best for straight forward parallel work. You still review the devs. But the orchestration grant work is gone. In summary, slash simplify ships cleaner code. Slash batch ships bigger changes faster. Save this and follow for more.
