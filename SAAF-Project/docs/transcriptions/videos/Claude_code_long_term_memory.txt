Here's how I give Cloud Code long-term memory with just three Cloud Code skills. Skill 1 is called memory and this is where all the memories are actually stored. This memory skill is structured very differently to your average skill, where normally in a skill you would just have a folder that has a bunch of files and maybe scripts in it, whereas this memory skill is actually a tree of branching folders that you can keep going down deeper into to get to more niche and specific memories. Skill 2 is called REM sleep, which tells Cloud Code to deploy a background sub-agent to read the transcript of the conversation that you've been having with it, and store all that information somewhere in the memory skill. Skill 3 is called Recall. This tells Cloud Code to deploy a background sub-agent to actually go to that memory skill and look through all of the memories that might be relevant to whatever project that you're tackling with Cloud Code, and pass them back to Cloud Code so they can take action based on its previously stored memories. This is a very simplified description of how this system really works. In reality, it's very complicated with a lot of moving parts, but if you want to get a similar system going, this is a really great place to start with these three core memory skills.
