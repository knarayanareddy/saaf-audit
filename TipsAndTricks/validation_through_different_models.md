# Validation through different models

## Opus vs Sonnet
Within Claude there are multiple models available and they have their own strengths.

As a good practice ask a different model (ie when you let Opus write code, ask Sonnet, or vice versa) to do a code review on what the other model made.
This does not per se give a better result, but surely it will find something the initial model did not find.

It's up to you to allow the reviewer model to accept the (code) changes.
